06 / MaintenanceImprove from failures
Skill development loop

Evidence before expansion.

Capture a real misfire or recurring friction.

Choose the smallest suitable mechanism.

Define triggers, near-negatives, and outcomes.

Record a baseline.

Make the smallest responsible revision.

Run targeted isolated trials.

Promote failures to regressions.

Consolidate or retire weak overlap.

Source: design, Skill Development Loop07
The repository no longer treats a new skill as the default solution to every repeated instruction. Skill-development first chooses among a skill, global instruction, project documentation, command, dedicated agent, deterministic tool, or no change. Real failures become compact regression fixtures.
